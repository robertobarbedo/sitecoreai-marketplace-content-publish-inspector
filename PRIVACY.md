# Privacy Policy

**Last Updated: July 13, 2026**

## Overview

The Publish Inspector is committed to protecting your privacy. This privacy policy explains our data collection and usage practices.

## Data Collection

**We collect anonymous usage analytics only.**

This application uses Google Analytics to collect basic, anonymous usage
metrics: page loads and an "app initialized" event, together with the
standard technical information Google Analytics gathers (browser type,
approximate location derived from IP, device category).

This application:
- Does **NOT** collect any personal information
- Does **NOT** send any of your Sitecore content, item data, or credentials
  to analytics — analytics events contain no content data whatsoever
- Does **NOT** store any user data on external servers beyond the anonymous
  Google Analytics metrics described above
- Does **NOT** share any information with third parties other than Google
  Analytics as described above

## How the Application Works

The Content Publish Inspector operates entirely within your browser and communicates directly with your Sitecore XM Cloud instance through:
- Sitecore Authoring GraphQL API
- Sitecore Delivery GraphQL API (Preview and Live endpoints)
- Direct HTTP requests to your website for verification

All data displayed in the application:
- Comes directly from your Sitecore environment
- Is processed locally in your browser
- Is never transmitted to our servers
- Is never stored beyond your browser session

## Local Storage

The application uses browser local storage only for:
- Saving your UI preferences (e.g., selected language, settings)
- Caching data temporarily for performance

This data:
- Remains on your device only
- Is never transmitted anywhere
- Can be cleared at any time by clearing your browser data

## API Communication

All API requests are made directly from your browser to your Sitecore instance. The application acts as a client-side interface only and does not proxy, intercept, or store any API responses.

## Third-Party Services

This application uses **Google Analytics** for anonymous usage measurement
(page views and app-load events). Google Analytics may set cookies in the
application's iframe for this purpose. See Google's privacy policy at
https://policies.google.com/privacy for details on how Google processes this
data. No other third-party analytics, tracking, or advertising services are
used.

## Changes to This Policy

We may update this privacy policy from time to time. Any changes will be reflected in the "Last Updated" date at the top of this document.

## Contact

If you have any questions about this privacy policy, please open an issue in the project repository.

## Your Rights

Beyond the anonymous usage metrics described above, we collect no data, and there is no personal information to request, modify, or delete. You have complete control over any local preferences stored in your browser.
