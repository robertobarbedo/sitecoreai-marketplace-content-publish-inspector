# Data usage disclosure

Content Publish Inspector is a read-only debugging app that runs inside
SitecoreAI. It reads content through the Sitecore Marketplace SDK with the
signed-in user's own permissions and shows it in the browser. It has no
database, writes nothing to the Sitecore content tree, and uses no
analytics. The app's server is used only to fetch your public website pages
for the Website check. Hosting: Vercel; serverless functions run in the
United States (Vercel default region `iad1`, Washington, D.C.) unless the
deployment sets another region.

See also the [Privacy policy](PRIVACY.md) and [Security policy](SECURITY.md).
